# Lecture des preuves

Les fichiers rhel9-lab.txt, ubuntu24-lab.txt et lsblk-*.txt au niveau de ce dossier correspondent aux exports directs de l’environnement A du 25 octobre 2026. Ils sont identiques aux originaux de env-a/.

env-a/ contient les huit exports reçus : deux états système, deux sorties de partitionnement, deux contrôles locaux et deux tests d’accès. Les dates, messages, erreurs et codes de retour ont été conservés.

env-b/ contient quatre extraits des relevés du 22 octobre issus du compte rendu d’installation. Leurs en-têtes identifient cette origine. Les prochaines collectes B les remplaceront par des exports directs.

Les captures sont dans ../captures/. La collecte Windows sauvegarde les anciennes versions dans historique/ ; ces sauvegardes locales sont exclues du dépôt Git.
